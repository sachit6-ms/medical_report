# AI-Based Medical Report Summarization & Condition Separation

A full-stack, local-first Python Flask medical report summarization and condition separation web application powered by **Local Ollama** and **Llama 3.2 3B**. 

Operates **100% locally and free of charge** without any paid cloud APIs (no OpenAI, Gemini, or Claude API required). All protected health data stays strictly private on the host machine.

---

## Key Features

1. **Patient Medical Condition Separation**:
   - **Patient Information**: Name, Patient ID, MRN, Age, Gender, DOB, Phone, Email, Doctor, Hospital, Report Date.
   - **Sensitive Information Detection**: Detects Protected Health Information (PHI) categories with a 1-click **Mask Sensitive Information** toggle that dynamically redacts values with `[REDACTED]` across the dashboard and PDF report without altering original files.
   - **Documented Diagnoses**: Strictly extracts explicitly documented diagnoses from clinical impressions/conclusions (never assumes diagnoses from lab values).
   - **Patient Medical Conditions**: Separates known chronic conditions and clinical history.
   - **Reported Symptoms**: Separates explicit patient complaints and symptoms.
   - **Clinical Findings**: Separates physical exam observations, vital signs, and imaging notes.
   - **Laboratory Results Table**: Extracted tabular results with Test Name, Value, Unit, Reference Range, and Status classification (`NORMAL`, `HIGH`, `LOW`, `ABNORMAL`, `UNKNOWN`). Prefers report's own reference ranges.
   - **Normal & Abnormal Findings**: Visual breakdown cards highlighting parameters requiring clinical attention.
   - **Medications / Treatments Mentioned**: Extracts Name, Dose, Frequency, Route, and Duration.
   - **AI Medical Summary**: Structured clinical narrative generated by local Llama 3.2 3B.
   - **Important Notes**: Doctor follow-up instructions and recommendations.
   - **Extracted Report Text**: Full PyMuPDF text viewer with copy-to-clipboard functionality.

2. **Medical Safety Guardrails**:
   - Does **NOT** claim to diagnose the patient.
   - Does **NOT** invent diseases, symptoms, or medications.
   - Does **NOT** recommend unprescribed treatments.
   - Does **NOT** alter numerical laboratory values.
   - Explicitly displays the required medical disclaimer across all UI views and generated PDF reports:
     > *"This system summarizes information present in the uploaded medical report for educational purposes. It is not a medical diagnosis and should not replace evaluation by a qualified healthcare professional."*

3. **Publication-Ready PDF Export**:
   - Generates an official, styled PDF report via ReportLab containing all separated medical categories, status badges, and disclaimer banners. Supports sensitive information masking.

## Local Ollama Setup

### 1. Start Ollama Service

Ensure Ollama is running on your machine. In PowerShell:

```powershell
ollama serve
```

*(If Ollama is already running in your Windows system tray, this step is already active).*

### 2. Pull the Llama 3.2 3B Model

Run:

```powershell
ollama pull llama3.2:3b
```

Verify that the model is installed:

```powershell
ollama list
```

Expected output:
```
NAME           ID              SIZE      MODIFIED
llama3.2:3b    a80c4f17acd5    2.0 GB    ...
```

## Common Errors and Fixes

### 1. `Ollama is not running. Please start Ollama and make sure llama3.2:3b is installed.`
- **Cause**: Ollama is not running in the background.
- **Fix**: Open a terminal and run `ollama serve`, or open the Ollama tray app from Windows Start Menu. The web app automatically uses deterministic rule-based analysis as a safe fallback so it will never crash.

### 2. `Model 'llama3.2:3b' was not found in Ollama`
- **Cause**: The model has not been downloaded yet.
- **Fix**: In PowerShell, run `ollama pull llama3.2:3b`.

### 3. `No extractable text found in the PDF. This may be an image-only or scanned document.`
- **Cause**: Uploaded PDF consists of scanned raster images with no embedded text stream.
- **Fix**: Upload digital text-based medical reports or PDFs with extractable text layers.

### 4. `llama-server binary not found`
- **Cause**: Ollama installation on Windows was interrupted before unzipping runners in `AppData\Local\Programs\Ollama\lib\ollama`.
- **Fix**: Re-run `OllamaSetup.exe` with administrator privileges or allow it to finish extracting completely.
